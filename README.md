# مواقيت الصلاة

صفحة عربية لعرض مواقيت الصلاة حسب الموقع:

- البحث عن مدينة أو استخدام موقع الجهاز.
- بيانات المكان والخريطة من OpenStreetMap عبر Nominatim وخرائط OSM.
- مواقيت الصلاة من [Aladhan Prayer Times API](https://aladhan.com/prayer-times-api)، مع إمكانية اختيار طريقة الحساب.

## التشغيل

افتح `index.html` عبر خادم محلي أو استضفه على HTTPS. يلزم الاتصال بالإنترنت لتحميل الخريطة وواجهات البيانات، كما يلزم HTTPS (أو localhost) للسماح بتحديد الموقع في المتصفح.

## إضافة Chrome

1. افتح `chrome://extensions` في Chrome وفعّل **وضع المطوّر**.
2. اختر **تحميل إضافة غير مضغوطة** وحدد مجلد `chrome-extension`.
3. افتح الإضافة من شريط الأدوات، ثم ابحث عن مدينتك أو اسمح بتحديد موقعك.

تُحفظ المدينة وطريقة الحساب محليًا في Chrome. تحتاج الإضافة إلى اتصال بالإنترنت للوصول إلى Nominatim وAladhan.

لتوليد حزم اختبار CRX وXPI داخل `chrome-extension/test`، شغّل:

```sh
python3 chrome-extension/test/build_packages.py
```

ملف CRX يُوقّع بمفتاح اختبار مؤقت يتجدد عند كل تشغيل؛ الحزم للاختبار فقط وليست للنشر أو التحديث المستمر.
